Zephyra

A modular, privacy-first AI assistant that runs entirely on your own machine — no API key, no cost, no data leaving your computer.

Try the live demo View source on GitHub

What it does

Local-first

Runs on Ollama, fully offline. Your conversations never leave your machine.

Persistent memory

Remembers context across a conversation with a sliding window — no endless context bloat.

Built-in tools

Time, date, calculator, and system info — handled deterministically, not guessed by the model.

Clean architecture

Brain, memory, and tools are fully separated — the same logic powers both the CLI and the web UI.
